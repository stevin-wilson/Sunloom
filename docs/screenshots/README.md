# Screenshots

The pictures shown in the [README](../../README.md) and the [user guide](../USER_GUIDE.md). Each is a real capture of the signed
release. To refresh one, replace the file under the same name; no document needs to change.

| File | Shows | Capture notes |
|---|---|---|
| `setup.png` | Setup, step 1 (Welcome), with **Start with defaults** visible. | Fresh install. Light theme. |
| `home.png` | **Home**: the current picture with Next, Previous, Keep and Dislike, and the status bar above it. | A real photograph, not the drawn first-start picture. Window about 1200 × 670. |
| `reserve.png` | **Reserve** in **Grid** view with a mix of light and dark pictures. | Let a fetch finish first so the cards are real pictures. |
| `schedule.png` | **Schedule** with *Sunrise & sunset* chosen and a city set. | Use a city, never your own address or exact coordinates. |
| `about-image.png` | **About this image**: author, licence and source of a picture, with *Report this image…* and *Close*. | Open it from Home → ⋮ More on a Wikimedia or NASA picture. |

## How to capture

- Use the signed release, in a window about 1200 × 670 (the same size for every shot, so the pictures line up).
- PNG, under about 400 KB each (an optimizer such as `oxipng` or `pngquant` helps). Do not show your name, account,
  notifications or anything outside the Sunloom window.
- Keep the file names above: the README and the user guide link to them.
